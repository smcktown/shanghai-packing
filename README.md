# Shanghai family packing checklist (de-identified)

Interactive tick-off packing list for a 8-day / 7-night cold-weather family trip.

- **Matrix view** — every item x every person, tap any cell
- **Per-person view** — one tab per traveller, tap to check off
- **Filters** — to pack / packed / to buy / must / last minute
- Progress bar; checkboxes persist on-device (localStorage), nothing is uploaded

De-identified: roles instead of names, no dates, hotel, policy or medication names.

On iPhone: open in Safari -> Share -> **Add to Home Screen**.
